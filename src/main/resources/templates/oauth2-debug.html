⚠️ Verificaciones Importantes

  • Google Cloud Console: Verifica que el Redirect URI esté configurado exactamente como: http://localhost:8080/login/oauth2/code/google
  • Client ID y Secret: Asegúrate de que las credenciales en application.properties sean correctas
  • Dominios autorizados: Agrega localhost y localhost:8080 en Google Console
  • APIs habilitadas: Verifica que Google+ API y OAuth2 API estén habilitadas

✅ URLs que deben funcionar

  • GET /oauth2/authorization/google - Inicia el flujo OAuth2
  • GET /login/oauth2/code/google - Callback de Google (manejado automáticamente)
  • GET /login?error=oauth2 - Página de error OAuth2
  • POST /logout - Cerrar sesión

🔍 URLs de Google para debugging

Puedes probar manualmente construyendo esta URL:

https://accounts.google.com/o/oauth2/v2/auth?response_type=code&client_id=CLIENT_ID&scope=openid%20profile%20email&state=RANDOM_STATE&redirect_uri=http://localhost:8080/login/oauth2/code/google

📝 Pasos para solucionar problemas:

  1. Verifica Google Console: Ve a Google Cloud Console
  2. APIs & Services > Credentials
  3. Busca tu OAuth 2.0 Client ID
  4. Edita y agrega estos Authorized redirect URIs:
    • http://localhost:8080/login/oauth2/code/google
    • http://localhost:8080/oauth2/callback (alternativo)
  5. Autoriza estos dominios:
    • localhost
    • localhost:8080
